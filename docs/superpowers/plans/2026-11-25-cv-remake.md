# CV Remake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three LaTeX CVs with one-page, single-column HTML/CSS CVs (en, ru, uz) printed to PDF by headless Chrome, with a photo, for local DevOps / Cloud / System Administrator job applications.

**Architecture:** Per-locale JSON content files feed one HTML template and one stylesheet. `cv/build.mjs` renders each locale and prints `public/cv/shaxriyor-jabborov-cv-<locale>.pdf` through `/usr/bin/google-chrome --headless`, failing unless the result is exactly one page. A node test guards content parity across locales and that every number on the CV already appears on the site.

**Tech Stack:** Node 24 (ESM `.mjs`, `node:test`), headless Chrome, `sharp` (already in `node_modules`) for the photo crop, Inter via the `@fontsource-variable/inter` dev dependency (latin, latin-ext, cyrillic), `pdftotext`/`pdfinfo`/`pdftoppm` for verification.

**Spec:** `docs/superpowers/specs/2026-11-25-cv-remake-design.md`

## Review Focus

1. **Russian overflows to page 2** (longest language): the build must fail, and the shipped content must fit; test is the one-page check in the build (Task 3).
2. **Uzbek apostrophes and Cyrillic render or extract wrong** (`'`, `oʻ`, `ё`, `й`): `pdftotext` output must contain the exact strings (Task 3).
3. **Parsers read the page out of order or the photo swallows text**: `pdftotext` (reading order) must show name, titles, contact, then Summary, Experience, Skills, Education, Languages (Task 3).
4. **A locale drifts**: different bullet counts, missing key, or a number that is on no site page (Task 1 test).
5. **Links break or are not clickable**: `mailto:`, `tel:`, `https://t.me/shaxadev` annotations exist in each PDF (Task 3).
